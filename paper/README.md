# `paper/` — a short software paper

A two-page description of `rcta` for **arXiv**, category `physics.ins-det`
(Instrumentation and Detectors), cross-listed to `physics.data-an` (Data
Analysis, Statistics and Probability). It is a software paper: what the tool
does, how the statistics are handled, and what it refuses to claim. There is
no pedagogy angle and no classroom material — that framing was dropped when
the target moved to arXiv.

- `paper.tex` — the whole paper. Standard `article` class, two columns, no
  `.bib` (the bibliography is inline), figures pulled from `../docs/`.
- `Makefile` — `make` runs `pdflatex` twice; `make clean` removes the output.

The source, `Makefile` and built `paper.pdf` are tracked; the LaTeX
by-products (`.aux`, `.log`, `.out`) are in `.gitignore`.

## Building

Needs a TeX distribution. BasicTeX is enough:

```sh
brew install --cask basictex
export PATH="/Library/TeX/texbin:$PATH"   # or open a new login shell
make
```

`microtype` and `booktabs` are already in BasicTeX, contrary to what an
earlier note here claimed. What BasicTeX does *not* ship is a scalable T1
Computer Modern, so `\usepackage{lmodern}` is loaded in the preamble: without
it, microtype's font expansion fails hard with `auto expansion is only
possible with scalable fonts` and no PDF is produced. The alternative is
`sudo tlmgr install cm-super` (~60 MB); Latin Modern is free and looks the
same.

Current state: **2 pages, builds with zero warnings and zero overfull boxes.**

Two pages is tight. The text alone very nearly fills them, so the figures fit
only because `\textfloatsep`, `\intextsep` and the caption skips are reduced
in the preamble and the bibliography is `\footnotesize` with no item
separation. If you add a paragraph, something else has to go — and note that
a `figure*` spanning both columns costs roughly 558 pt of column height
against 2748 pt available, which is why the walking-survey figure is a
single-column `figure`.

## Where the numbers come from

Every figure quoted is printed by the CLI on the bundled tracks, or stated in
the repository documentation and pinned by a test:

```sh
rcta-cli analyze "sample-data/Track 07 Sep 2026 14-30-57.rctrk"  # the walk
rcta-cli analyze "sample-data/Track 07 Sep 2026 07-53-59.rctrk"  # the flight
```

The walk supplies 348 samples / 2.99 km, the 5.31 cps background, the 7.36 and
4.57 sigma features, the 126 effective samples and the two dose totals
(80.9 vs 153.8 nSv). The flight supplies the MDA table and the 4.57 sigma
Bonferroni threshold. The 5.2x raw-distance error, the 0.25-quantile bias, the
0.9985 lag-1 autocorrelation and the 863-test count come from `README.md`,
`docs/FLIGHT.md` and the suite itself.

All of the above were re-verified against a live run when the paper was
retargeted; the repository README had drifted (it quoted 1160.02 and 132.60
nSv/h where the tool prints 1159.97 and 132.56) and was corrected to match.

## Figures

`../docs/screenshot-walk.png` is regenerated by `../tools/shoot.py`, which
drives the real Qt application offscreen rather than compositing anything, so
the figure is what a user actually sees. It uses the **USGS National Map
imagery** basemap: public domain, therefore publishable without condition.
Do not switch it to Esri World Imagery — that layer is marked
`allow_export: false` in `providers.json` precisely because its terms tie it
to an ArcGIS licence, and a figure in a preprint is redistribution.
